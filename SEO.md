# NexusCompress SEO & AI visibility

Last updated: 2026-08-11

## Inventory (approximate)

- Sitemap URLs: generated by `scripts/generate-sitemap.js` (homepage EN/AR, about EN/AR, legal, guides hub, UAE + general guides, 12 tools × EN/AR, `llms.txt`)
- Guides: `public/guides/*.html` (EN + AR UAE cluster)
- Tool entry points: `/tools/{slug}/` via `scripts/generate-tool-pages.js`
- AI discovery: `/llms.txt`, `/llms-full.txt`, `/.well-known/llms.txt`
- Entity: Organization (Fun Adventure Media Studio) + WebApplication on homepage; About page; `sameAs` → GitHub

## Policies

- FAQPage JSON-LD only on `/guides/*` (see `scripts/seo-faq-policy.js`) — not on SPA homepage
- Independent product disclaimer on UAE pages; always link official `.gov.ae` sources
- `hreflang` uses `en` + `ar-AE` + `x-default`

Engines: ChatGPT (search), Perplexity, Gemini, Google AI Overview.

## Notes

`llms.txt` helps agents discover preferred URLs; it is **not** a Google ranking signal. Citation lift comes mainly from deep guides + entity clarity + third-party mentions.
