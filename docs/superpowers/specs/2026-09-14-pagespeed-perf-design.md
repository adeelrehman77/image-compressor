# PageSpeed Performance Pass — Design Spec

**Date:** 2026-09-14  
**Goal:** Mobile and Desktop Lighthouse Performance ≥ 90 on `/` and `/ar/`.

## Locale requirement (non-negotiable)

Improvements MUST apply to **English and Arabic** equally:

- Edit `public/index.html` only for markup/script tags — **never** hand-edit `public/ar/index.html`.
- Arabic pages are generated by `scripts/generate-ar-index.js` during `npm run build` into `dist/ar/` (and tool pages under `dist/ar/tools/*/`).
- Shared JS/CSS (`tools-router.js`, build minify, tokens) automatically covers both locales.
- Verification must assert **both** `dist/index.html` and `dist/ar/index.html` (no eager ONNX, same defer strategy, `<main>` present, RTL still `dir="rtl"`).

## Problem summary

| Issue | Impact |
|-------|--------|
| Eager `ort.min.js` on every page | Large unused JS, parse/compile cost |
| Desktop `preloadToolsIdle()` loads 7 tools | Explains Desktop TBT ~7.7s vs Mobile ~360ms |
| Blocking head scripts (`i18n.js` ~144KB, etc.) | Render-blocking / main-thread work |
| Unminified first-party JS | PSI minify + unused JS noise |
| Missing `<main>` + fragile ARIA list | A11y / agentic browsing |

## Approach

Surgical load-path fixes (no bundler rewrite, no i18n split).

1. Remove eager ONNX `<script>` from `public/index.html` (AI Upscaler already lazy-loads via `loadExternalScript`).
2. Remove `preloadToolsIdle()` scheduling (or no-op it) in `tools-router.js`.
3. Keep `locale.js` **synchronous** in `<head>` (sets `lang`/`dir`/`__NEXUS_LOCALE` before paint — critical for Arabic RTL).
4. Add `defer` to `i18n.js`, `tool-meta.js`, `tool-routes.js`, `ads-config.js`.
5. Minify first-party JS in `dist/` during `scripts/build.js` with esbuild (already a dependency).
6. Wrap tool panels + SEO/FAQ in `<main class="app-main">` for landmark + existing `.app-main` CSS hooks.
7. Fix workflow steps ARIA: remove invalid `role="list"` / mixed children (or drop roles).
8. Contrast: raise dark-mode `--text-muted` if still failing after structural fixes (token-level, both locales).
9. `verify-dist.js`: fail if eager ONNX CDN tag remains in EN or AR index.

## Out of scope

HSTS / COOP / Trusted Types, full critical-CSS extraction, locale-split i18n bundles, CSP redesign.

## Success criteria

- PSI Mobile ≥ 90 and Desktop ≥ 90 on `https://compress.funadventure.ae/` after deploy.
- Same load behavior on `/ar/` (no English-only path).
- Compress + tool switch + AI Upscaler ONNX-on-demand still work in EN and AR.
- `npm test` / `verify-dist` pass.
